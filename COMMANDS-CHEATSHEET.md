# Claude Commands Cheat Sheet

## 🚀 Quick Commands

```bash
/workflow <description>   # Full dev workflow
/plan <feature>           # Planning
/implement <task>         # Implementation
/autonomous <goal>        # Auto orchestration
/context                  # Context analysis
/research <topic>         # Research

/skills                   # Show this menu
```

## 🤖 Agents (claude agent <name>)

```bash
# Analysis & Investigation
brahma-analyzer           brahma-investigator

# Development
code-implementer          chief-architect
implementation-planner    brahma-test-generator

# Operations
brahma-deployer          brahma-ci-runner
brahma-monitor           brahma-healer

# Quality & Security
brahma-optimizer         brahma-security-scanner
brahma-dependency-resolver

# Orchestration
brahma-orchestrator
```

## 💡 Examples

```bash
# Start a workflow
/workflow add user authentication with JWT

# Run an agent
claude agent brahma-analyzer

# Plan a feature
/plan implement caching layer

# Research
/research best practices for API design
```
