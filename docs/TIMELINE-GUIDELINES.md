# Timeline Guidelines for Claude Code

**Important**: When estimating implementation time, use Claude Code timelines, not human developer timelines.

## Realistic Implementation Times

### Simple Features (10-20 minutes)
- Basic data collection/tracking
- Simple analysis scripts
- Configuration changes
- Documentation updates
- Minor integrations

### Medium Features (30-60 minutes)
- Pattern detection algorithms
- Multi-strategy implementations
- Moderate integrations
- Dashboard components
- Testing frameworks

### Complex Features (1-3 hours)
- Machine learning implementations (RL, Bayesian opt, etc.)
- Full web dashboards with backend
- Multi-system integrations
- Advanced analysis pipelines
- Complete subsystems

## Key Differences from Human Development

| Task Type | Human Time | Claude Code Time | Factor |
|-----------|-----------|------------------|---------|
| Simple script | 2-4 hours | 10-20 minutes | 10-15x |
| Medium feature | 1-2 days | 30-60 minutes | 20-30x |
| Complex feature | 3-7 days | 1-3 hours | 50-100x |

## Why Claude Code is Faster

1. **No context switching** - Continuous focus
2. **Parallel processing** - Can work on multiple parts simultaneously
3. **Instant recall** - No research/ramp-up time needed
4. **No debugging cycles** - Write correct code first try (usually)
5. **Automated testing** - Built-in validation as we go
6. **No meetings/interruptions** - Pure implementation time

## Communication Guidelines

### ❌ Don't Say:
- "This will take 2-3 days"
- "We can implement this next week"
- "That's a week of work"
- "Give me a few days for that"

### ✅ Do Say:
- "This will take 30-45 minutes"
- "I can implement this now"
- "That's about an hour of work"
- "Give me 20 minutes for that"

## Reality Check Examples

**Real-Time Dashboard:**

**Reinforcement Learning:**

Users should expect:
- Simple improvements: **Ready in minutes**
- Medium improvements: **Ready within the hour**

This is not hyperbole - this is the actual capability of Claude Code.
