## 🚀 Quick Start

### Prerequisites
- Python 3.10+
- Redis (for caching)
- Git

### Installation

```bash
git clone https://github.com/wallon-qodo/ai-efficiency-optimizer-.git
cd .claude
python3 -m venv venv
source venv/bin/activate
pip install agentlightning numpy scipy
git clone https://github.com/microsoft/agent-lightning.git
```
